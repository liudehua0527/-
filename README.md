# 截图分拣台（Prototype）

一个可视化图片分拣工具原型，适合把知乎/推特/其他截图快速分类到项目目录。

## 功能

- 选择**源图片文件夹**与**项目输出文件夹**。
- 快捷键分类（默认）：
  - `1` → 推特
  - `2` → 知乎
  - `3` → 其他入库
  - `4` → 其他不入库
- 两种策略：
  - 即时执行（每次按键立即复制/剪切）
  - 延迟批量（先打标签，最后统一执行）
- 文件操作模式：复制 / 剪切。
- 撤回：`Z`（撤回上一次执行）。
- 批量执行：`A`。
- 分段组：`G`（新建组号，用于同一文章连续截图）。
- 自动重命名（可选）：`前缀_时间_来源_G组_序号`。
- 从文件名中解析元信息，如：
  - `Screenshot_2025-10-29-15-02-52-619_com.twitter.android.jpg`
  - 时间：`2025-10-29-15-02-52-619`
  - 来源：`com.twitter.android`

## 运行

直接在现代浏览器中打开 `index.html`。

> 说明：目录读写依赖 File System Access API，建议使用 Chromium 内核浏览器（Chrome / Edge）。

## 快捷键

- `1/2/3/4` 分类
- `←/→` 上一张/下一张
- `Z` 撤回
- `A` 应用待执行队列
- `G` 新建分段组
